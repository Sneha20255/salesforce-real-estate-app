# Salesforce Real Estate App

My first Salesforce project to manage Properties!

## What I Built
- Custom Object: Property
- Fields: Price (Currency), City (Text), Bedrooms (Number), Status (Picklist - For Sale / For Rent / Sold)
- Records Created: Sunshine Villa (Adilabad), Green House (Hyderabad), Lake View Hous

## Skills Learned
Salesforce Setup, Object Manager, Custom Objects, Fields, Records, Lightning App
